# 更新记录

## v0.1.1（2026-10-21，实验预发布）

- 用户实测 v0.1.0 识别到 NFC 标签，但固件握手或 transceive 失败，电池供电也复现。
- 板端捕获 GPIO 软件 I²C 高频轮询中的 HardFault；改为原板引脚 SERCOM1 硬件 I²C（约100 kHz）。关闭主循环睡眠/NVM 自动睡眠与缓存用于稳定性诊断，尚未实现低功耗。
- 50 ms 空闲轮询，先看一个 SRAM 块，有请求再读剩余块；为 RF 留出空闲时间。镜像每500 ms检查，丢失则重新初始化，初始化失败每秒重试。
- Android 身份握手最长等待6秒；日志包含手机型号、Tag UID、READ原始响应、失败命令；失败弹窗可“复制诊断”，不需 root/Shizuku。
- 错误文案不再把 TagLost 简单归因于用户移动手机。APK versionCode=2，同开发密钥签名，可覆盖原版。
- 已通过 Java 图像/协议测试、APK v2/v3签名验证、实板 SERCOM1 SRAM整图接收/重复包/CRC/刷新/DONE/EEPROM比较；手机端到端传图仍待重测。
