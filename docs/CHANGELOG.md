# 更新记录

当前推荐组合为 **Android v0.1.4 + 固件 v0.1.2**。以下倒序排列；实验记录和发布附件保留原状。

## 2026-10-22 · 仓库整理

- 重写使用入口，集中版本兼容、签名、哈希、接线、故障排查与验证状态。
- 去除当前文档中重复的旧故障段落，明确用户已确认 v0.1.2 手机上传成功。
- 补充架构、协议扩展字节说明、贡献流程、离线校验和 Java 核心 CI。
- 清理本机目录依赖，APK 输出名从 Manifest 读取；没有改动 MCU/Android 业务逻辑，也未重新烧录。

## v0.1.4 · 2026-10-21

- 删除首页“图片编辑”“调整画面，贴近上传。”和预览标题。
- 预览独立为固定圆角窗，滚动下方图像调整时保持可见。
- 选择、顺时针旋转 90°、图片信息与裁切缩放移入图像调整。
- 修正圆弧和箭头连接，方向与旋转操作一致。
- versionCode 5，同开发签名，兼容固件 v0.1.2。构建/核心测试通过，新布局待手机验收。

## v0.1.3 · 2026-10-21

- 应用名改为墨屏，重做浅色卡片界面与分阶段上传弹窗。
- 新增 0–100% 抖动强度；0% 关闭、100% 保持旧结果。
- 等待连接、传输和刷新期间常亮，结束、取消、失败及后台后释放。
- 原创像素 SVG、五档 PNG 与 Adaptive Icon。
- versionCode 4，兼容固件 v0.1.2，新 UI/常亮待手机验收。

## v0.1.2 · 2026-10-21

- 用户日志能读到完整 EPA1，但首次 A204 写失败。旧邮箱04h..13h 落入本板锁页。
- 静态锁 F0 FF、动态锁 FF 00 00；动态锁位于 I²C block38h 的字节8..10。
- 邮箱迁移到未锁 RF90h..9Fh，会话镜像块24h、LAST_NDEF_BLOCK=27h，布局修订2；只读检查目标锁位，保留全部锁位和持久配置。
- 手机最后块读后静默90 ms，MCU延迟20 ms再访问；presence-check间隔1秒，RF场存在时先只读会话寄存器。
- 整图、重复包、错误偏移、CRC拒收、刷新/DONE、Flash辅助区和896字节EEPROM比对通过。
- APK versionCode 3。发布时尚待手机验证；用户随后反馈“可以了”，确认手机上传成功。

## v0.1.1 · 2026-10-21

- GPIO I²C 高频轮询曾捕获 HardFault；改 SERCOM1 硬件 I²C，降低轮询并留 RF 空闲时间。
- 镜像每500 ms检查，初始化失败重试；关闭主循环/NVM自动睡眠和缓存用于诊断。
- 身份握手最长6秒，诊断包含手机、UID、READ和失败命令；不再把所有 TagLost 归因于移动。
- versionCode 2。实板路径和构建测试通过，但手机仍出现识别或 transceive 失败，已由后续版本替代。

## v0.1.0 · 2026-10-21

初版212×104编辑、选图/裁切/旋转、亮度/对比度、三色量化和EPD1协议。手机未成功上传，板端长时间运行出现异常。仅保留作历史记录。
